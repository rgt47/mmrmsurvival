# Data Directory

This directory holds the simulated data products for the
MMRM-vs-Cox AD trial simulation study
(`analysis/report/report.Rmd`). **No real patient data are
used anywhere in this project.** All files listed below are
either directly generated by scripts in `analysis/scripts/`
or are re-derivable from them.

`raw_data/` and `derived_data/` are unused, empty
placeholders inherited from the zzcollab project template;
this project has no external raw data source, so nothing is
staged there.

## Simulation output files

| File | Producing script | Contents | Regeneration |
|------|------------------|----------|---------------|
| `sim_results.rds` | `analysis/scripts/01_run_simulation.R` | 2000-replication primary simulation output (per-replication MMRM/Cox estimates); a stale run from an earlier code state (see caveat below) | `Rscript analysis/scripts/01_run_simulation.R` |
| `sim_power_vs_n.rds` | `analysis/scripts/02_power_vs_n.R` | Power-vs-sample-size sweep (`n_per_arm` in 100/150/200/300/400 at 200 reps/cell), feeding Figure \@ref(fig:power-comparison) | `Rscript analysis/scripts/02_power_vs_n.R` |
| `sim_13.rds` | ad hoc / superseded driver, not currently produced by any script in this repository | An archived list containing per-replication RNG states and a `summary` data frame whose values match the numbers reported in the manuscript's Table 1 (MMRM power 0.994, Cox power 0.716) | not regenerable from the current scripts as-is; kept as an archival snapshot of the run that produced the manuscript's reported numbers |

**Caveat on `sim_results.rds`:** as of this revision, the
copy of `sim_results.rds` on disk was generated by an
earlier, since-corrected version of `sim_study.R` and shows
0 valid Cox model fits out of 2000 replications; it does
not match the numbers reported in the manuscript and should
not be used without first regenerating it via
`Rscript analysis/scripts/01_run_simulation.R`. The numbers
actually reported in the manuscript come from the report's
own cached `run-simulation` knitr chunk (see
`analysis/report/cache/`) and, consistently, from
`sim_13.rds`.

The report itself (`report.Rmd`) does not read any of these
`.rds` files directly for its primary results; it re-runs
`run_simulation()` from `sim_study.R` on each render (see
the `run-simulation` chunk), using the seed and RNG kind
pinned in the setup chunk. Only the `power-comparison`
figure chunk reads a cached `.rds`
(`sim_power_vs_n.rds`), because that sweep is run by a
separate script rather than inline in the report.

## Data/code availability statement

All simulation parameters, data-generating code, and
analysis code for this manuscript are contained in this
`mmrmsurvival` research compendium
(`analysis/scripts/sim_study.R`,
`analysis/scripts/01_run_simulation.R`,
`analysis/scripts/02_power_vs_n.R`,
`analysis/report/report.Rmd`), with package versions pinned
via `renv.lock`. No human-subjects data were used. The
manuscript's headline results are reproducible by rendering
`analysis/report/report.Rmd` with
`bash tools/render.sh analysis/report/report.Rmd` after
first running `Rscript analysis/scripts/02_power_vs_n.R` to
populate the sample-size sweep figure's cached input.
